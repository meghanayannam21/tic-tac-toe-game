# Tic Tac Toe Game

A simple Tic Tac Toe game created using HTML, CSS, and JavaScript.

**Play the Game:** [Click Here][(https://meghanayannam21.github.io/tic-tac-toe-game/)]

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Two-player game.
- Player X and Player O take turns.
- Checks the winner automatically.
- Displays a message when the game is a draw.
- New Game and Reset Game options.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start playing!
