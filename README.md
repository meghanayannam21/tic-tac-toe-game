# Tic Tac Toe Game

This is a simple Tic Tac Toe game created using HTML, CSS, and JavaScript. Two players can play the game by taking turns marking X and O on a 3 × 3 board.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Two-player game.
- Player X and Player O take turns.
- Checks the winner automatically.
- Displays a message when the game is a draw.
- New Game and Reset Game options.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open the `index.html` file in your browser.
4. Start playing the game!

## Project Files

- `index.html` – Creates the game structure.
- `style.css` – Adds styles to the game.
- `app.js` – Contains the game logic.
